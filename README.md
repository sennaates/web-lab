# Web LAB-1 ve LAB-2

## Hakkinda

Bu proje, Web Tasarimi ve Programlama dersi kapsaminda Vite + React + TypeScript kullanilarak olusturulmus, erisilebilirlik (a11y) standartlarina uygun kisisel portfoy sayfasidir.
